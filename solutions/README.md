# Solutions

A complete answer for every lesson. Try the exercise yourself first. If your version passes the tests, it's a good answer, even if it looks different from these.

To run a solution against the tests, copy it into the lesson folder as `exercise.py` (keep a copy of yours first), then run `python3 -m unittest -v` there. Lessons 9 and 10 read files from their lesson folder, so run those from there too.
